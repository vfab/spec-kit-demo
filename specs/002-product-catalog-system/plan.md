# Implementation Plan: Product Catalog System

**Branch**: `002-product-catalog-system` | **Date**: 2026-03-22 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/002-product-catalog-system/spec.md`

---

## Summary

Build the customer-facing product catalog UI layer on top of the existing Epic 1 data foundation: paginated product listing with AJAX filtering/sorting, product detail pages with reviews and recently-viewed tracking, full-text search with autocomplete, session-based product comparison, and administrative review moderation. All models and core views already exist; Epic 2 adds the missing templates, the review submission flow, autocomplete, comparison, recently-viewed tracking, and the low-stock status property.

---

## Technical Context

**Language/Version**: Python 3.12, Django 5.0.2
**Primary Dependencies**: Django (CBVs, sessions, admin, cache), Pillow (image resize — already integrated), python-decouple (settings), Bootstrap 5 (frontend), Fetch API / vanilla JS (AJAX)
**Storage**: SQLite (development), PostgreSQL (production); Django ORM; Django file-based media for images; Django LocMemCache (dev) / configurable cache backend
**Testing**: pytest 8, pytest-django, pytest-cov, factory-boy; test files in `tests/`
**Target Platform**: Linux server (Django WSGI)
**Project Type**: Full-stack Django web application (MTV pattern)
**Performance Goals**: Product listing and search results pages load within 2 seconds for up to 10,000 active products (SC-002); autocomplete responds in <100ms
**Constraints**: ≥95% test coverage (Constitution §III); 100% test pass rate before any commit (Constitution §II); all 7 pre-commit gates must pass; no new migrations required (all schema changes already in Epic 1)
**Scale/Scope**: Up to ~10k products per spec assumptions; single-tenant store; UP TO 8 recently viewed / 3 compared products per session

## Implementation Phases

### Phase 1 — Model & Admin Additions (No Migration)

1. Add `stock_status` property to `Product` model (reads `settings.LOW_STOCK_THRESHOLD`)
2. Add `stock_status` property to `ProductVariant` model
3. Add `ProductReviewAdmin` to `products/admin.py` (list_display, bulk approve action)
4. Add `settings.LOW_STOCK_THRESHOLD = 5` to `ecommerce_site/settings.py`

### Phase 2 — Review Submission

1. Create `products/forms.py` with `ReviewSubmissionForm`
2. Add `ReviewSubmitView` to `products/views.py` (LoginRequiredMixin, duplicate guard)
3. Register URL: `products/<slug>/review/` → `ReviewSubmitView`
4. Extend `ProductDetailView.get_context_data()` — add `reviews`, `review_form`, `user_existing_review`

### Phase 3 — Search Autocomplete

1. Add `AutocompleteView` to `products/views.py` (JSON, ≥2 chars, max 10 results)
2. Register URL: `products/autocomplete/` → `AutocompleteView` (before slug route)
3. Write `static/js/autocomplete.js`

### Phase 4 — AJAX Filtering

1. Override `render_to_response` in `ProductListView` to detect `format=partial` and return `_product_grid.html` fragment
2. Write `templates/products/_product_grid.html` partial
3. Write `static/js/filters.js` (Fetch API, replaces grid DOM node)

### Phase 5 — Recently Viewed

1. Add recently-viewed session logic to `ProductDetailView.get_context_data()`
2. Add `recently_viewed` to context (batch-fetched products)
3. Add recently-viewed shelf to `product_detail.html`

### Phase 6 — Product Comparison

1. Add `ComparisonAddView`, `ComparisonRemoveView`, `ComparisonView` to `products/views.py`
2. Register comparison URLs (before slug route)
3. Write `templates/products/compare.html`
4. Write `templates/products/_compare_widget.html`
5. Write `static/js/comparison.js`

### Phase 7 — Missing Templates

1. Write `templates/products/category.html`
2. Write `templates/products/search_results.html`
3. Extract `templates/products/_product_card.html` partial
4. Update `templates/products/product_list.html` (filter pills, recently viewed, AJAX hooks)
5. Update `templates/products/product_detail.html` (reviews, review form, recently viewed)

### Phase 8 — Tests & Quality Gates

1. Extend `tests/test_products.py` to cover all above
2. Run full test suite: `pytest tests/ --cov --cov-report=term-missing`
3. Run all 7 quality gates (flake8, mypy, bandit, pip-audit, pre-commit)
